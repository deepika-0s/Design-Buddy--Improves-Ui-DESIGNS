# 🎨 DesignBuddy AI

> AI-powered UI design analyzer — upload screenshots, choose your aesthetic vibe, and get instant expert-level feedback.

---

## 🚀 Overview

**DesignBuddy AI** is a smart web application that helps developers, designers, and creators improve their UI/UX designs instantly.

Just upload your UI screenshots, select your preferred design aesthetic, and get **AI-driven insights powered by Google Gemini**.

---

## ✨ Features

* 📸 **Multi-Screenshot Upload**

  * Upload & analyze multiple UI screens at once

* 🎯 **Aesthetic Detection**

  * Choose from:

    * Minimalist
    * Glassmorphism
    * Brutalist
    * Soft UI
    * Gen Z / Modern

* 🤖 **AI Design Feedback**

  * Powered by **Google Gemini**
  * Get suggestions on:

    * Layout
    * Color usage
    * Typography
    * Spacing & hierarchy

* 🌐 **Live Preview Support**

  * Analyze UI via links or screenshots

* ⚡ **Real-Time Analysis**

  * Fast and responsive insights

* 📱 **Mobile-Friendly**

  * Works smoothly across devices

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/designbuddy-ai.git
cd designbuddy-ai
```

---

### 2. Setup Backend

```bash
cd backend
npm install
npm start
```

---

### 3. Setup Frontend

Open new terminal:

```bash
cd frontend
npm install
npm run dev
```

---

### 4. Open in Browser

```
http://localhost:3000
```

---

## 🔐 Environment Variables

Create a `.env` file inside `/backend`:

```
GEMINI_API_KEY=your_api_key_here
```
